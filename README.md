# شنكال – ملحمة الصمود

**SHINGAL — RESISTANCE** لعبة عربية ثلاثية الأبعاد بمنظور الكتف، تتبع آزاد وأمه شيرين وأخته روجين عبر ثمانية فصول خيالية. تستلهم الحملة شجاعة المجتمع الإيزيدي خلال اعتداءات داعش على شنكال. تتمحور الأهداف حول العائلة والإنقاذ وإصلاح مرافق الحي وحفظ الذاكرة.

## التشغيل المحلي

استخدم Node.js 22.18 أو أحدث. افتح مجلد المستودع ثم نفّذ الأوامر التالية.

```sh
npm ci
npm run dev
```

افتح العنوان الذي يطبعه Vite. لتشغيل نسخة الإنتاج واختبار التثبيت والحفظ دون اتصال، نفّذ الأوامر التالية.

```sh
npm test
npm run build
npm run preview
```

## اللعب

تحرّك بمفاتيح WASD، ووجّه الكاميرا بالفأرة بعد النقر في المشهد. استخدم الزر الأيمن للتصويب والأيسر للإطلاق. يلقّم R السلاح، ويقفز Space، ويركض Shift، ويبدّل C وضع الانحناء. اضغط E قرب المعيّن الذهبي لتؤدي الهدف. يستخدم H حقيبة إسعاف ويبدّل 2 أداة الدفاع. تفتح Escape قائمة التوقف. تتاح إعادة توزيع المفاتيح من الإعدادات.

على شاشة اللمس، حرّك العصا بإصبع ووجّه الكاميرا بإصبع آخر. يمكن تبديل مواضع الأزرار وحساسية النظر. تفتح العلامة الفيروزية ذكرى اختيارية على الخريطة. يفتح إنهاء كل فصل الفصل التالي. تتبع الشخصية المُنقذة آزاد إلى المحطة التالية. تزيد الخبرة المكتسبة من الفصول والذكريات سعة تجهيز الفصل اللاحق. تُحفظ الأهداف والمقتنيات والحالة تلقائيًا في المتصفح ويمكن الحفظ اليدوي من قائمة التوقف.

## التحقق في المتصفح

تختبر الحزمة واجهة الإنتاج تحت مسار فرعي، وحفظ نقطة تفتيش واستعادتها، واللعب دون اتصال، وإدخال اللمس المتزامن في مقاسين أفقيين. كما تشغّل دورة المحاكاة عبر الفصول الثمانية بفاصل زمني ثابت وتتحقق من الوصول إلى الأهداف والذكريات. تبدأ بخادم HTTP مؤقت على عنوان محلي وتغلقه بعد الاختبارات.

```sh
npm run build
npx playwright install chromium
npm run test:browser
```

يختار المتغير الاختياري `CHROMIUM_PATH` نسخة Chromium مثبتة. يحدد `SCREENSHOT_DIR` مجلدًا لحفظ لقطات حقيقية من الاختبار. يعتمد الأداء على دقة الشاشة وإعداد الرسوم ومشغّل WebGL.

## النشر والتثبيت

ينتج البناء ملفات ثابتة في `dist/`. يستخدم Vite مسارات نسبية لدعم GitHub Pages داخل مجلد المستودع. يتضمن المشروع إعدادات Netlify وVercel وسير عمل Pages للفرع main. اختر **GitHub Actions** كمصدر Pages عند نشر نسخة أخرى من المستودع.

عند الزيارة الأولى باستخدام HTTPS أو localhost، يخزّن عامل الخدمة ملفات الحملة والخطوط والصور. بعد اكتمال التخزين يمكن إغلاق التبويب وإعادة فتح اللعبة دون اتصال. يعرض المتصفح المثبّت خيار التثبيت حيث يدعمه النظام. على Safari في iOS يمكن استخدام «إضافة إلى الشاشة الرئيسية». يُفعَّل تحديث الحزمة بعد إغلاق النسخة السابقة.

تحتاج اللعبة إلى WebGL 2. يعتمد الحوار المنطوق على وجود صوت عربي على الجهاز، وتظهر جميع الجمل مكتوبة. تفاصيل الملكية والمصادر واردة في [سجل الأصول](ASSETS.md).
