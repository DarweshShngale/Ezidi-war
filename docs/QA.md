# اختبار إصدار شنكال

اختُبرت حزمة الإنتاج المبنية من الالتزام `e444649ff4f4bd29ad39ec40d8f5d66621669239` تحت المسار الفرعي `/Ezidi-war/`. تعرض الصور المرفقة إطارات التقطها المتصفح من اللعبة.

## النتائج الوظيفية

| الاختبار | النتيجة |
| --- | --- |
| فحص TypeScript وبناء Vite وإنتاج عامل الخدمة | نجحت الخطوات الثلاث. تضم قائمة التخزين دون اتصال ٣٠ ملفًا. |
| اختبارات الوحدات | نجحت الاختبارات الستة للحفظ والتقدم وإعادة اللعب والتصادم وحجب الأشعة وتوجيه الشخصيات. |
| الحملة كاملة | عبرت المحاكاة نقاط التفاعل الأساسية الأربع والعشرين وجمعت الذكريات الثماني. استخدمت الحركة والتفاعل والخصوم الفعليين بخطوة زمنية ثابتة، مع تعطيل الرسم المتكرر خلال هذا الفحص. |
| مسار اللاعب في Chromium | نجحت الحركة إلى الهدف الأول، والتفاعل، وتغيير المفاتيح، والحفظ اليدوي، وإعادة التحميل، ثم متابعة الهدف الثاني. |
| التثبيت والعمل دون اتصال | فُحص بيان التطبيق، وانتظر الاختبار جاهزية عامل الخدمة، ثم قطع الشبكة وأعاد تحميل الصفحة واستأنف المشهد المحفوظ. |
| اللمس | تحركت الشخصية بالعصا بالتزامن مع تدوير الكاميرا بإصبع ثانٍ. نجح القفز والانحناء وضبط موضع زر اللمس وحفظه في مقاسين أفقيين، وفُحص عرض القائمة رأسيًا. |
| WebKit 26.0 على Linux | فُتحت القائمة والإعدادات والفصل الأول. تحركت الشخصية بمفتاح التقدم، ثم حفظ التوقف المؤقت موضعها الجديد. |
| Firefox | تعذّر تشغيل جلسة الاختبار في بيئة Linux المعزولة. توافق Firefox غير مؤكد في هذا الإصدار. |

## الأداء

استُخدم Chromium 156 على Linux بأربع وحدات معالجة افتراضية، مع SwiftShader للرسم البرمجي وإعداد الرسوم المنخفض. قياس إطار البداية يشمل تحميل المحرك وتهيئة المشهد والمُظلّلات. سجّل آخر اختبار شامل ١٠٫٣ ثانية من الضغط على «بدء اللعبة» إلى ظهور زر دخول المرحلة. سجّلت جولات سابقة بين ٧٫٥ و٨٫٣ ثانية.

بعد ست ثوانٍ لإحماء المشهد، قيس الفصل الأول لاثنتي عشرة ثانية لكل مقاس. ظلت اللعبة تستخدم ضبط الدقة التلقائي أثناء القياس.

| مساحة العرض | المقاس بوحدات CSS | الإطارات المرصودة | المدة بالثواني | المتوسط، إطار/ثانية |
| --- | --- | ---: | ---: | ---: |
| سطح المكتب | 1360 × 840 | 146 | 12.1 | 12.1 |
| محاكاة iPhone أفقية | 844 × 390 | 273 | 12 | 22.7 |
| محاكاة Android أفقية | 915 × 412 | 254 | 12.06 | 21.1 |

لا تتوافر قياسات لهاتف فعلي أو بطاقة رسومية مستقلة. اختُبرت أبعاد الشاشة وإدخال اللمس بمحاكاة Chromium، واختُبر محرّك WebKit على Linux. يحتاج تثبيت التطبيق على شاشة iOS الرئيسية، وجودة النطق على أجهزة المستخدمين، وبلوغ هدف ٣٠–٦٠ إطارًا في الثانية، إلى اختبار الأجهزة المستهدفة.

## حدود الإصدار

الفصول قصيرة وتركز على لقاءات محددة ومرافقة ناجين وجمع ذكريات. تستخدم الشخصيات هندسة وتحريكًا إجرائيين. مشهد العنوان لوحة أصلية ذات عمق وحركة منظور وغبار لحظي. يستخدم اللعب نفسه عالماً ثلاثي الأبعاد وكاميرا متحركة. يختار السرد صوت النظام العربي عند توفره، وتبقى كل الجمل متاحة نصيًا.

## تكرار الاختبارات

```sh
npm ci
npm test
npm run build
npx playwright install chromium
npm run test:browser
```

يُعيد `npm run test:browser -- --benchmark` قياس معدل الإطارات في المقاسات الثلاثة بعد إحماء المشهد. يمكن تشغيل فحص الحملة وحده باستخدام `npm run test:browser -- --campaign-only`. يلتقط `npm run test:browser -- --gallery` مشاهد من أربعة فصول عندما يُضبط `SCREENSHOT_DIR`. يستخدم معرض الصور سجلات حفظ اختبارية لاختيار الفصل، ثم يدخل من زر المتابعة العادي.
